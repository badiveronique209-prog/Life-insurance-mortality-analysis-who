# Life Insurance Mortality Analysis - WHO

Actuarial project Life Insurance branch. 
Analysis of factors influencing life expectancy using WHO Life Expectancy Dataset.

Complements my Non-Life project (Auto Insurance Pricing with GLM) to show a full actuarial profile: Non-Vie + Vie.

**Methods:** Multiple Linear Regression, Logistic Regression, EDA
**Stack:** Python, pandas, scikit-learn, seaborn
**Dataset:** https://www.kaggle.com/datasets/kumarajarshi/life-expectancy-who
